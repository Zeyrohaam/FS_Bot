# FreakingStarsBot6

## Запуск

- Для запуска бота: `python main.py`
- Для запуска через launcher: `python start.py`
- Для проверки структуры проекта: `python scripts/check_project.py`

## Конфигурация

Режим работы задаётся через `APP_MODE` в [config.py](config.py):
- `test`
- `prod`

## Desktop-админка (Windows)

Приложение запускается отдельным окном и подключается к FastAPI на компьютере или сервере. Оно не использует Telegram WebApp и не требует менять версию Telegram.

1. На сервере добавьте в `.env` секрет `DESKTOP_ADMIN_KEY`. Создайте случайный ключ командой `python -c "import secrets; print(secrets.token_urlsafe(32))"` и не публикуйте его.
2. Если бот запускается через `python start.py`, возьмите напечатанный адрес `Адрес API для админ-приложения`. Этот запуск уже поднимает backend и Cloudflare Quick Tunnel.
3. Если бот уже запущен отдельно через `python main.py`, не запускайте `start.py` поверх него: это запустит второй экземпляр бота. Вместо этого запустите на сервере `python -m miniapp`, а в другом окне терминала выполните `cloudflared tunnel --url http://127.0.0.1:8080`. Оставьте оба процесса работающими и возьмите выданный HTTPS-адрес туннеля.
4. На своём компьютере запустите desktop-приложение, введите этот HTTPS-адрес и тот же `DESKTOP_ADMIN_KEY`. Укажите только адрес без `/webapp` и без `/admin`.

Quick Tunnel меняет адрес после перезапуска. Для постоянного адреса настройте домен и HTTPS reverse proxy или постоянный Cloudflare Tunnel к локальному backend (`127.0.0.1:8080`). Не открывайте порт backend в интернет без HTTPS и ограничения доступа.

Для запуска desktop-приложения из исходников установите зависимости: `pip install -r admin_desktop/requirements.txt`, затем выполните `python admin_desktop/admin_desktop.py`.

Для сборки отдельного `.exe` установите те же зависимости и запустите `admin_desktop/build_admin.bat`. Исполняемый файл появится в `admin_desktop/dist/FreakingStarsAdmin.exe`.

Админка управляет ценами и NFT, параметрами бота и ID администраторов, балансами пользователей, их игровой статистикой, промокодами, предложениями и рассылками. Корректировки балансов журналируются; изменения runtime-параметров применяются работающим ботом. Токен бота и desktop-ключ не открываются в приложении; смена токена или режима работы требует настройки на сервере и перезапуска.
